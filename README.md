# AI Chatbot Web Application

This is an AI chatbot project built using Python and Flask.
The frontend is made using HTML, CSS, and JavaScript.

## Project Structure

CHATBOT-PROJECT/
├── frontend/
│   ├── index.html
│   ├── script.js
│   └── style.css
├── models/
│   └──
├── app.py
└── README.md

## Features
- AI based chatbot
- Clean web interface
- Frontend and backend separated
- Easy to understand code
- Ready for deployment

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## How It Works
- Frontend sends user message using JavaScript
- Flask backend processes the message
- AI model generates response
- Response is shown on the web page
